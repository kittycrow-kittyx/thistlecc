# Driver types

| Export | Purpose |
| --- | --- |
| `VERSION` | Driver release |
| `Language` | Automatic, C or C++ selection |
| `Stage` | Compiler stage |
| `EmitKind`, `ExtensionKind` | Output format and suffix |
| `ColourMode` | Diagnostic colour policy |
| `ThistleccConfig`, `ConfigLoadResult` | Configuration and discovered file path |
| `CliOptions` | Resolved invocation options |
| `ResolvedTools` | Host command and converter paths |
| `ElfSummary`, `ThxSummary` | Validated binary identity |
| `Manifest` | Build provenance and file hashes |

| `JsonValue`, `JsonObject` | JSON value grammar used at parsing boundaries |
